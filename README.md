# MSFLOW – Installer und Updates

MSFLOW ist eine Windows-Anwendung für Bildschirmaufnahme, Videoschnitt und YouTube-Animationen.
Dieses Repository enthält **nur** die Installer und Update-Pakete, keinen Quellcode.

## Herunterladen und installieren

1. Neueste Version öffnen: **https://github.com/sabitzerm-isd/msflow-releases/releases/latest**
2. `MSFLOW-win-Setup.exe` herunterladen und starten.
3. Die Installation braucht keine Administratorrechte und landet in `%LOCALAPPDATA%\MSFLOW`.

Windows SmartScreen kann warnen, weil der Installer nicht signiert ist:
**„Weitere Informationen“ → „Trotzdem ausführen“**.

## Updates

MSFLOW prüft beim Start auf neue Versionen und zeigt unten rechts einen Hinweis.
Ein Klick lädt nur die geänderten Teile und startet die Anwendung neu.
Abschaltbar unter *Einstellungen → Updates*.

## Nach dem Neuaufsetzen eines Rechners

Installer wie oben herunterladen. Die Einstellungen lassen sich beim ersten Start aus der
OneDrive-Sicherung (`MSFLOW-Sicherung`) wiederherstellen.

## Voraussetzungen

Windows 10 (Version 2004) oder Windows 11, 64 bit.
